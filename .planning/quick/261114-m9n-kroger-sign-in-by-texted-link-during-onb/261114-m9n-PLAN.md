- Rewrites: `{ "$schema": "https://openapi.vercel.sh/vercel.json", "rewrites": [{ "source": "/k/:state", "destination": "/api/k?state=:state" }] }`. The docs say named params "pass through in the query string" but tell you to verify on a deployment. So the handler reads `state` from the query AND falls back to the last path segment when the path starts with `/k/`.
- `@vercel/blob` (private stores need >= 2.3): `put(pathname, body, { access: 'private', contentType, addRandomSuffix: false, allowOverwrite, cacheControlMaxAge })`. Writing an existing pathname throws unless `allowOverwrite`, and the minimum `cacheControlMaxAge` is 60. `get(pathname, { access: 'private', useCache: false })` returns `null` when the blob is missing, otherwise `{ statusCode, stream, headers, blob }`; `useCache: false` reads from origin and guarantees the latest write. `del(urlOrPathname | urls[])` does not throw when the blob is missing. `list({ prefix, limit })` returns `{ blobs: [{ url, pathname, uploadedAt, ... }], cursor, hasMore }`.
- Credentials: `vercel blob create-store <name> --access private --yes`, run in the linked project, connects the store to all environments. On Vercel the SDK then authenticates through OIDC (`VERCEL_OIDC_TOKEN` + `BLOB_STORE_ID`, both added automatically). `BLOB_READ_WRITE_TOKEN` is only a fallback outside Vercel. So the relay code needs NO token env var.
- Deployment Protection protects preview and per-deployment URLs. The texted link must use the project's production domain (`https://<project>.vercel.app`).

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Phone browser to relay (public) | Anyone can request /k/* and /api/kroger/callback with any query |
| Agent Mac to relay claim | Outbound HTTPS; the relay must give codes only to the secret holder |
| Relay to Vercel Blob | Private store; OIDC credentials provided by the platform |
| Kroger redirect to relay | The code arrives in a query string; Kroger checks redirect_uri |
| Tool results to the voice model | Results are spoken; they must carry no link, state or account data |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-m9n-01 | Information disclosure | relay claim | mitigate | Bearer RELAY_SECRET (32 chars or more), compared via sha256 + timingSafeEqual; 401 without it; 503 if unset |
| T-m9n-02 | Spoofing / CSRF | OAuth state | mitigate | 256-bit random state from crypto, strict 43-char URL-safe check at the relay; the claim is keyed by the exact state the agent created |
| T-m9n-03 | Information disclosure | stored code | mitigate | Private Blob store; only the code (no secret, no tokens); deleted on claim; claim refuses and deletes anything over 10 min; sweep on each callback; reads with useCache:false |
| T-m9n-04 | Tampering (XSS) | callback pages | mitigate | Only Kroger's `error` is echoed, escaped and cut to 40 chars; CSP default-src 'none'; nosniff; no code or state in any page |
| T-m9n-05 | Information disclosure | Referer / caches | mitigate | Referrer-Policy no-referrer and Cache-Control no-store on every relay response |
| T-m9n-06 | Denial of service | Blob store spam via callback | accept | Format and size checks, 10-minute sweep, and a low-value target; signed states were considered and left out to keep the agreed state design |
| T-m9n-07 | Information disclosure | logs and tool results | mitigate | Tests capture console output and stringify results to check that no secret, code, token or state appears; the agent never returns the link |
| T-m9n-08 | Spoofing (texting) | text_kroger_sign_in | mitigate | Recipient is only the configured PATIENT_PHONE (actions also enforces it); 60 s resend window; fixed message text |
| T-m9n-09 | Elevation | Kroger client secret | mitigate | The secret never leaves the Mac; the relay env has only KROGER_CLIENT_ID and RELAY_SECRET |
| T-m9n-SC | Tampering | @vercel/blob dependency | mitigate | Package name from vercel.com docs (official); exact version pinned after `npm view`; types read from the packed tarball; not installed locally; installed only by Vercel at the human-run deploy |
