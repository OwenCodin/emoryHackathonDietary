## Phase Goal

**As a** patient standing in front of a store shelf, **I want to** hear which product in view is the best choice for my limits, **so that** I can pick it without reading every label.

<objective>
When the camera shows a shelf with two or more products, look_at_camera picks the best one with a pure ranking function (D-01) and returns one spoken sentence that names it, verdict word first (D-02). The instructions tell the model to lead with that sentence, keep store replies to one sentence, and never invent a product (D-03). The renal stub's describeImage always returns a plate, so the shelf path is proven offline with an injected fake renal module (D-10). One simulated call checks that the prompt change did not break a spoken check.

Purpose: AISL-01, the in-aisle twist.
Output: pickBest and the shelf branch in agent/tools.mjs, tests, the prompt rules, and a regression call in the SUMMARY.
</objective>
