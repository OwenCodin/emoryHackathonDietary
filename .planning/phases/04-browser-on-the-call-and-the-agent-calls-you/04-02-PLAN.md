@livekit/agents 1.8.0, voice namespace (dist/voice/room_io/room_io.d.ts, _output.d.ts, agent_session.js):
- RoomInputOptions.participantIdentity?: string, "The participant to link to".
- RoomIO.start() runs init() as a background Task (session.start does not wait for it). init() waits on participantAvailableFuture, which resolves only when a participant with that identity is in the room, and only then calls participantAudioOutput.start(signal), which publishes the agent's audio track named roomio_audio. So participantIdentity = bridgeIdentity alone would publish no audio until the bridge joins. This is the case CONTEXT.md "Specific Ideas" anticipated.
- voice.ParticipantAudioOutput is exported at runtime (typeof function). Its constructor is (room: Room, options: { sampleRate: number; numChannels: number; trackPublishOptions: TrackPublishOptions; queueSizeMs?: number }). start(signal: AbortSignal): Promise<void> publishes the track at once, then awaits publication.waitForSubscription() (it resolves only after someone subscribes, so never await it in entry). close(): Promise<void> closes its AudioSource.
- RoomIO's own defaults are audioSampleRate 24000, audioNumChannels 1, audioPublishOptions new TrackPublishOptions({ source: TrackSource.SOURCE_MICROPHONE }) and queueSizeMs 200. Use the same values.
- AgentSession.start: when session.output.audio is already set, RoomIO keeps it ("RoomIO audio output is enabled; preserving and using the existing output.audio" is logged as a warning) and does not create or publish a second audio track. RoomIO.close() does not close an external output, so the agent must close it.
- @livekit/rtc-node exports TrackPublishOptions (runtime function) and TrackSource.

livekit-server-sdk 2.19.3: RoomServiceClient.listParticipants(room): Promise<ParticipantInfo[]>; ParticipantInfo has identity: string and tracks: TrackInfo[]; TrackInfo.type is TrackType, exported at runtime with TrackType.AUDIO = 0 and TrackType.VIDEO = 1. AgentDispatchClient.createDispatch(roomName, agentName, { metadata }). updateRoomMetadata(room, metadata).

agent/greet.mjs (do not edit): greetOnBridgeReady(room, greet) calls greet once when room.metadata has chert_bridge_ready === true; returns stop().

agent/agent.mjs (as left by plan 04-01; read 04-01-SUMMARY.md and the file): entry does watchCaller(ctx.room) then await ctx.connect() then const caller = await ctx.waitForParticipant() and logs '[agent] call joined caller=<identity>'.
