## Phase Goal

**As a** teammate on Track B or Track C, **I want to** clone the repo, run `npm install`, `npm start` and `npm test`, and import stub `renal` and `actions` modules that match the shared contract, **so that** I can build my track on my own branch without waiting for anyone.

(The ROADMAP goal line for Phase 1 is "A teammate can clone the repo, start the agent process, and develop their own track against stubs that match the shared contract". The three slots above restate that line and add nothing to it.)

<objective>
Build the Walking Skeleton for this Node ES-module voice agent. `npm start` boots the agent process, which imports `shared/video.mjs`, builds its one tool (`check_food`) from the `renal` stub, and waits for a call. `npm test` calls every stub function and checks the contract's shapes. No API keys, no phone and no real call are needed.

Purpose: two teammates are blocked until this scaffold exists. Every later Track A phase adds a slice on top of it without changing its layout.
Output: root `package.json` + `package-lock.json`, `.gitignore`, `.env.example`, `shared/video.mjs`, stub `renal/index.mjs` and `actions/index.mjs`, `agent/{agent,greet,chert-rooms,face,tools}.mjs`, `agent/contract.test.mjs`, and a Getting started section in the root `README.md`.

Tasks run in vertical-slice order: (1) a failing end-to-end contract test, (2) the thinnest slice that makes it pass (stubs, shared constants, the tool), (3) the agent process wired to that slice so `npm start` boots.

Git: commit per task on the current `agent` branch. Do NOT switch, create, merge or push branches. Merging to `main` is the person's decision after the phase.
